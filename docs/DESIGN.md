# 아아 장인 — 디자인 기준 (DESIGN.md)

이 문서는 화면 UI(글자·버튼·카드·가림막)의 기준이다. 3D 장면(기기·컵·손)의 모양과 색은 [CLAUDE.md](../CLAUDE.md)의 결정 사항을 따른다.
구현 위치: `index.html`의 `<style>` 맨 앞 `:root` **디자인 토큰**과 **공통 클래스**(`.btn`, `.btn-primary` …).

## 0. 읽는 법

| 표시 | 뜻 |
|---|---|
| **[코드]** | `index.html`에서 실제로 확인한 값 (토큰 정리 전부터 쓰던 값 포함) |
| **[화면]** | 헤드리스 크롬(PC 1440×900, 아이폰 가로 844×390 터치 에뮬레이션)과 사용자 아이폰 스크린샷에서 눈으로 확인한 것 |
| **[새로 정함·시작값]** | 이번에 처음 정한 숫자. 확정값이 아니라 **시작값**이다. 실제 기기에서 써 보고 고친다 |

### 화면 목록과 목적 (그대로 유지)

| 화면 | 목적 | 요소 |
|---|---|---|
| 시작 | 모드 고르기 | 제목, 모드 카드 3개(1분 도전·3잔 도전·연습, 카드 안 최고 기록), 게임 설명 링크, 홈 화면 추가 안내(아이폰 사파리만), 불러오는 중/실패 안내 |
| 게임 설명 | 규칙 읽기 | 제목, 목표 한 줄, 5단계 목록, 규칙 문단, 닫기 |
| 게임 | 아이스 아메리카노 만들기 | 3D 장면, 왼쪽 위 한 줄(잔 수·시간·최고), 그 아래 경고 한 줄, 기기 위 남은 초, 오른쪽 아래 완성, 그 위 내려놓기(터치·뭔가 들었을 때), 오른쪽 위 그만하기(3잔·연습) |
| 결과 | 기록 보기 | 제목(영업 종료/3잔 완성/연습 끝), 큰 숫자, NEW RECORD, 기록 한 줄, 다시 하기·메뉴로 |
| 회전 안내 | 폰 세로일 때 | "가로로 돌려 주세요" |
| 오류 상자 | 개발용 (맥 없이 아이폰 디버깅) | 왼쪽 위 빨간 상자 |

### 분위기 (브랜드 느낌)

- 3D 장면: 실제 카페 사진 색감(흰 서브웨이 타일, 스테인리스, 검정 기기) + **검은 외곽선** 로우폴리. **[코드]** `COL`, 외곽선 `#111`
- 화면 UI: **컴팩트·조용함**. 이모지 없음, 동작마다 뜨는 글자 없음, 게임 화면을 최대한 가리지 않음. 참고: 아이스크림 높이 쌓기 게임처럼 작은 흰 글자 + 알약 버튼. **[코드]** · **[화면]**
- 3D 장면은 밝고 UI 글자는 흰색 → 게임 위 글자는 **그림자**, 메뉴는 **어두운 가림막** 위에 둔다.

### 단위 (웹 → 플랫폼)

이 게임은 웹(HTML 하나)이라 코드 단위는 CSS px이다.
- **iOS 사파리**: CSS 1px = **1pt** (아이폰 가로 기준 약 6px/mm, 아이폰 13 화면으로 계산)
- **Android 크롬**: CSS 1px = **1dp**. 글자는 **sp**로 적는다. `text-size-adjust: 100%`로 브라우저 자동 확대를 꺼 두어서, 기본 글자 크기 설정에서는 sp = dp다. 사용자가 시스템 글자를 키우면 크롬 설정에 따라 커질 수 있다(확인 못 함).

## 4. 공통 컴포넌트

입력 칸은 이 게임에 없다(이름·검색 등 글자 입력이 없음). 생기면 아래 버튼과 같은 높이(48)·모서리(카드 16)·흰 바탕으로 시작한다. [시작값]

### 4-1. 버튼 `.btn` + 종류

모든 화면 버튼은 `.btn` 하나에서 시작하고 **종류 클래스 하나**를 붙인다. 같은 역할은 같은 모양·동작, 다른 역할은 다른 모양. **[새로 정함]** (기존엔 화면마다 따로 스타일이 있었음 **[코드]**)

| 종류 | 클래스 | 모양 | 쓰는 때 | 지금 쓰는 곳 |
|---|---|---|---|---|
| 주 버튼 | `.btn .btn-primary` | 흰 알약, 진한 글자 | 그 화면에서 가장 할 일 하나 | 다시 하기, 닫기 |
| 보조 버튼 | `.btn .btn-secondary` | 투명 알약 + 흰 테두리 | 주 버튼 옆 다른 길, 게임 중 빠져나가기 | 메뉴로, 그만하기 |
| 글자 링크 | `.btn .btn-link` | 밑줄 글자만 | 부가 정보 열기 | 게임 설명 |
| 카드 | `.btn .btn-primary .btn-card` | 흰 사각(모서리 16), 위 이름 + 아래 작은 글 | 고르는 것이 여러 개이고 각자 정보가 있을 때 | 모드 3개 |
| 떠 있는 주 버튼 | `#done` (= `.btn-primary`, 반투명 흰) | 오른쪽 아래, 터치는 엄지 크기 | 게임 중 핵심 행동 | 완성 |
| 떠 있는 보조 버튼 | `#drop` (= `.btn-primary`, 더 투명) | 완성 바로 위 | 들고 있는 것 놓기 (터치에서 뭔가 들었을 때만) | 내려놓기 |

규칙
- 한 화면에 **주 버튼은 하나**(카드 묶음은 예외: 모드 고르기 자체가 주 행동).
- 가로로 나란히 놓을 땐 **주 버튼이 왼쪽**, 보조가 오른쪽 (다시 하기 | 메뉴로). [코드]
- 버튼 글자는 동사·짧게(2~4글자). 이모지·느낌표 없음. [코드]
- 3D 장면 안의 초록 추출 버튼은 **화면 버튼이 아니다** → 이 규칙을 적용하지 않음(장면 물건 규칙을 따름).

| 선택 | (UI) 해당 없음 — 모드는 고르면 바로 시작. (3D) 컵 1cm 떠오름 + 아래 흰 링 | 카운터 컵 2개 이상일 때 컵 | [코드] |
| 포커스 | 대표색 3px 테두리 (`:focus-visible`, 키보드로 옮길 때만) | 모든 `.btn` | [새로 정함·시작값] 기존엔 없었음 |
| 사용할 수 없음 | 투명도 0.4, 눌림 없음, 커서 기본 | 불러오는 동안 모드 카드 | [새로 정함·시작값] |
| 로딩 | 시작 화면 링크 아래 `불러오는 중…`(캡션, 글자 3) + 모드 카드 사용할 수 없음 → 준비되면 사라짐 | 3D 엔진(three.js) 받는 동안 | [새로 정함] 기존엔 카드를 눌러도 반응 없었음 |
| 내용 없음 | 짧은 회색 문장, 아이콘 없음 | 카드 `기록 없음` · 연습 `시간 제한 없음` · 결과 `완성한 잔이 없어요` | [코드] |
| 오류 (게임 규칙) | 경고 줄(주의색) + 짧은 삐 소리. 문장은 "무엇이 왜 + 할 일" | `탬핑된 원두가 없어요`, `삐— 샷 · 뚜껑 빠짐! (망쳤으면 싱크대에 버려요)` | [코드] |
| 오류 (불러오기 실패) | 12초 안에 준비 안 되면 로딩 문장을 오류색으로 바꿈 | `게임을 불러오지 못했어요. 인터넷 연결을 확인하고 새로고침해 주세요` | [새로 정함·시작값] 12초 |
| 오류 (개발) | 왼쪽 위 빨간 상자 | 자바스크립트 오류 | [코드] |
| 급함 | 남은 10초 이하 시간 글자 오류색 | 1분 도전 | [코드] |
| 신기록 | 대표색, 글자 간격 넓힘 | 결과 `NEW RECORD` | [코드] |

## 6. 적용 예시

**시작 화면** — 제목 + 카드 묶음 + 링크 + 상태 문장
```html
<div class="ov" id="ovStart">
  <h1>아아 장인</h1>
  <div class="cards">
    <button class="btn btn-primary btn-card" id="startTimed" disabled><b>1분 도전</b><small id="bestTimed"></small></button>
    …
  </div>
  <button class="btn btn-link" id="helpBtn">게임 설명</button>
  <p class="status" id="loadStatus">불러오는 중…</p>
</div>
```

**결과 화면** — 주 버튼 왼쪽, 보조 오른쪽
```html
<div class="row">
  <button class="btn btn-primary" id="againBtn">다시 하기</button>
  <button class="btn btn-secondary" id="menuBtn">메뉴로</button>
</div>
```

**게임 화면** — 정보 왼쪽 위, 행동 오른쪽
```
┌──────────────────────────────────────────────┐
│ 3잔  42초  최고 7                  [그만하기] │  ← 잔 수 줄 / 보조 버튼
│ 탬핑된 원두가 없어요                          │  ← 경고 줄 (1.6초)
│                                              │
│          (3D 장면, 기기 위 4.2 같은 숫자)      │
│                                  [내려놓기]   │  ← 터치 + 뭔가 들었을 때
│                                  [  완성  ]   │  ← 엄지 버튼 150×72
└──────────────────────────────────────────────┘
```

**새 버튼을 추가할 때** — 역할을 먼저 정하고 클래스만 고른다. 색·크기를 직접 쓰지 않는다.
```html
<button class="btn btn-secondary" id="soundBtn">소리 끄기</button>   <!-- 다른 길·빠져나가기 = 보조 -->
```
```css
/* 숫자가 필요하면 토큰으로 */
#soundBtn { margin-top: var(--gap-m); }
```

## 7. 아직 정하지 않은 것 / 확인 못 한 것

- 실제 아이폰·안드로이드에서 글자 크기(특히 폰 캡션 10)와 버튼 48의 체감 — 확인 못 함
- Android 크롬에서 홈 화면 설치·전체 화면, 시스템 글자 크기 키움 시 동작 — 확인 못 함
- 소리 켜기/끄기, 설정 화면은 아직 없음 (생기면 4-1 보조 버튼·카드 규칙으로)
