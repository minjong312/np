얼음 가득 · 물 80% · 샷 · 뚜껑 · 홀더를 채운 컵이 한 잔

  1. 컵 보관대 클릭 → 컵 꺼내기. 정수기 클릭 → 컵이 아래로 가서 물이 자동으로 참
  2. 아이스빈 클릭(스쿱 잡기) → 다시 클릭(얼음 푸기) → 컵 클릭
  3. 포터필터 핸들 클릭 → ← 드래그로 돌려 빼기 → 드로어 클릭(퍽 털기)
  4. 분쇄기 클릭(자동 분쇄) → 탬퍼 클릭 → 머신 클릭(결합) → 초록 버튼(추출)
  5. 샷잔 클릭 → 컵 클릭. 뚜껑 · 홀더 클릭 → 완성

원두는 결합하고 30초, 샷은 받고 1분이 지나면 못 써요. 망친 컵은 싱크대에.
컵이 2개 이상이면 컵을 클릭해 고를 수 있어요. 그룹 · 포터필터 · 샷잔은 2개씩.
우클릭 = 내려놓기 · Space = 완성 · Esc = 그만하기아이폰: 공유 → 홈 화면에 추가하면 전체 화면
